ATENÇÃO!!!

Conforme aviso disponibilizado, nesta página, em 13/08/2023, este serviço deveria ter sido descontinuado em 31/08/2024, e seus usuários migrados para a nova API. Mas, devido à solicitação de vários usuários, a ANA decidiu por prorrogar este período até 30/06/2026.

Entretanto, em virtude da grande defasem tecnológica, houve a necessidade de redirecionar o serviço para uma base de dados de secundária, que apresenta menor desempenho e possui uma pequena defasagem na atualização das informações.

Os usuários que desejam migrar para o novo serviço, mais moderno e completo, devem encaminhar um email para hidro@ana.gov.br, com o assunto "Solicitação de acesso à API". No corpo do e-mail, inclua uma breve explicação (em poucas linhas) sobre a motivação da solicitação e forneça as seguintes informações para o cadastro:

  • Nome do usuário ou instituição
  • CPF ou CNPJ (para ser utilizado como usuário)
  • Endereço de e-mail (será utilizado para o recebimento da senha de acesso)

Após o recebimento do e-mail nossa equipe irá avaliar sua solicitação e, caso necessário, entrar em contato para solicitar mais informações.

Link para o manual de acesso ao novo serviço: Tutorial de Serviço para Consumo de Dados - API HidroWebService
