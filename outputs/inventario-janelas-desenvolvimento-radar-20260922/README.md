# Janelas já usadas no desenvolvimento do Radar

Este índice evita chamar novamente de teste inédito uma janela que já orientou experimentos. Reúne julho/2020, maio/2021, maio–junho/2022, setembro/2023, abril–01/maio/2024 e os blocos originais de2025/2026. Os protocolos e seus hashes estão em `known-windows.json`.

É um índice parcial dos experimentos identificados, não uma prova de que qualquer data ausente esteja intacta. Antes de reservar uma nova janela, conferir também consultas brutas, relatórios de eventos, previsões e métricas já vistos. Saber data/pico por boletim é exposição prévia a ser declarada, mesmo antes de calcular erros de modelos.

As antigas reservas2021/2022 já foram avaliadas e são desenvolvimento conhecido. Nenhuma entrada deste índice comprova publicação histórica dos dados, continuidade da régua, independência de eventos ou cumprimento da meta prospectiva. Nenhum modelo foi treinado ou promovido nesta etapa.
